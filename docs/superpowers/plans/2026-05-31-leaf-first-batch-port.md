# Leaf First Batch Low-Risk Patch Port Implementation Plan

> **For AI Agent Workers:** Required subskill: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task by task. Steps use checkbox (`- [ ]`) syntax to track progress.

**Goal:** Port the first batch of low-risk, localized patches without threading model assumptions from Leaf `ver/1.21.11` to Canvas-PixelHavenFork.

**Architecture:** Port patch by patch: first apply Canvas generated sources, then modify corresponding NMS, Paper API, or Canvas-owned code, and finally rebuild patches through the paperweight patch process. Each patch is independently verified and committed to avoid introducing wide-scale conflicts.

**Tech Stack:** Java 21, Gradle, paperweight-weaver, Folia region-threading, Bukkit/Paper API, Canvas YAML configuration system.
